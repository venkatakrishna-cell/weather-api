 Weather API Web Application

Project Overview
A weather web application built using HTML, CSS, and JavaScript that integrates the OpenWeatherMap API to search for weather information by city.

Features
- Search for weather information by city.
- Retrieve weather data using the OpenWeatherMap API.
- Display API data through a web interface.

 Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
